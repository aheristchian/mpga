# Project Instructions

- **Internationalization (i18n):** ALL user-facing text must be added to the i18n localization files (e.g., `src/locales/en.json`). Do not hardcode English strings in templates or data structures that are displayed to the user.
- **Documentation Updates:** Whenever a new feature, phase, or significant architectural change is made, ALWAYS update the corresponding documentation in the `docs/` folder (e.g., `how-to-play.md`, `rules.md`, `roadmap.md`) to reflect the current state of the application.
